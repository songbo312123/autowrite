# 16-热点信息源配置

这份文件定义企业版 skill 在做资料搜集时，应该去哪里找一手信息。按优先级和内容类型分层，避免搜到一堆二手噪音。

## 一、信息获取路由

```
官方源（优先）→ 阅读器全文抓取 → RSSHub 兜底
```

原则：
- 能拿到官方 RSS/Feed 的，不经过第三方
- 官方没有 Feed 的，用 RSSHub 路由补
- 需要登录态或反爬严格的，走浏览器 CDP
- 情绪样本类内容，直接看评论区/社交平台

## 七、RSS 工具推荐

### 阅读器
- **NewsBlur**：支持全文抓取、规则过滤，适合跟踪和深度阅读
- **Inoreader**：适合管理大量订阅，有规则和过滤功能
- **Feedly**：界面简洁，适合轻量跟踪

### 路由补全
- **RSSHub**：官方文档 `docs.rsshub.app`，大量现成路由，没有原生 RSS 的站用它补

### 自建方案
- **Miniflux**：轻量自建 RSS 阅读器，适合技术用户
- **FreshRSS**：功能更全的自建方案

## 八、不同选题类型的信息源优先级

| 选题类型 | 最优先信息源 | 次优先信息源 |
|----------|-------------|-------------|
| 热点评论型 | 微博热搜、知乎热榜 → 一手报道 | 国际媒体、评论区情绪样本 |
| AI 相关 | AI 官方博客 → 机器之心/量子位 → arXiv | AI 评论博客、科技媒体 |
| 职场成长型 | 知乎、脉脉讨论 → 深度报道 | 谷雨/人物长文、国外职场媒体 |
| 搞钱/副业型 | 知乎搞钱话题 → 36氪/虎嗅 | 国外 side-hustle 内容 |
| 情感共鸣型 | 小红书、微博情感话题 → 深度报道 | 评论区金句、非虚构写作 |
| 知识解释型 | 学术源 → 专业媒体 → MIT Tech Review | Nature/Science、科普号 |
| 自媒体复盘型 | 爆文原文 → 数据平台 | 同行分析、评论 |

## 九、使用提醒

1. **一手信息优先**：能找到官方博客/公告的，不要用二手报道
2. **情绪样本最后看**：先搞清事实和观点，再看评论区找表达方式
3. **不要贪多**：每个选题 3-5 个核心来源就够了，多了反而淹没主线
4. **国际源是补充**：公众号读者主要在国内，国际信息要翻译成"和普通人有什么关系"
5. **AI 源要分层**：产品发布看官方博客，行业变化看 36 氪/机器之心，深度分析看 Simon Willison/Stratechery，论文看 arXiv
6. **定期清理**：不活跃的源及时取消订阅，保持信息信噪比
