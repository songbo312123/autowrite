# 05-开头与结尾技法库

开头负责留下人，结尾负责留下印象和传播理由。

## 一、开头的任务

公众号开头前三句最好完成三件事：
1. 抓注意力
2. 确认相关性
3. 给阅读理由

如果三段以后读者还不知道你想说什么，开头就失败了。

## 二、五种常用开头方式

### 1. 痛点直戳

适合：职场、成长、情感、搞钱类

特点：第一段直接说出现实困境。

示例句式：
- 这两年，我听过最多的一句话之一就是：
- 很多人不是不想___，而是___
- 你有没有发现，越来越多人都在___

优点：起效快，抓人强。
风险：如果只有痛感没有推进，会变成情绪宣泄。

### 2. 问题起手

适合：知识、方法、判断类

特点：直接抛出用户脑子里的那个问题。

示例句式：
- 为什么很多人明明___，却还是___？
- 普通人做___，到底最先该解决什么问题？

优点：相关性强，适合知识型阅读。
风险：问题太泛会显得空。

### 3. 故事起手

适合：情感、职场经历、人物感较强的文章

特点：用一句对话、一个朋友、一个具体时刻入场。

示例句式：
- 前几天，一个朋友在深夜给我发消息：
- 我有个朋友说过一句话，我一直记到现在。

优点：自然，代入感强。
风险：故事太长会拖慢入题。

### 4. 热点起手

适合：热点评论、趋势解读类

特点：直接接正在发生的公共事件。

示例句式：
- 这两天，___刷屏了。
- 每次看到___上热搜，我都会想到一个问题。

优点：借势拿注意力。
风险：如果只是复述新闻，没有观点，很快变浅。

### 5. 结果先给

适合：复盘、方法、经验型文章

特点：第一段先亮结果或结论。

示例句式：
- 我后来才发现，真正关键的不是___。
- 写了___篇之后，我越来越确定一件事。

优点：适合成熟读者，效率高。
风险：结论过轻会撑不起后文。

## 三、开头增强技巧

### 1. 一句对话
作用：立刻让场景活起来。

### 2. 高频生活场景
作用：让读者更快说出“这就是我”。

### 3. 反常识第一句
作用：让读者停下来确认你要说什么。

### 4. 情绪命名
作用：让读者感到被理解。

### 5. 阅读承诺
作用：告诉读者读下去能得到什么。

## 四、开头禁忌

- 不要寒暄半天
- 不要铺垫与主题无关的生活日常
- 不要开头太“对”，但不抓人
- 不要一上来讲大道理
- 不要把最关键的问题拖到很后面才说

## 五、结尾的任务

结尾不是礼貌收尾，而是传播设计的一部分。它至少承担下面一项，最好两项：
1. 总结出一句能被转述的判断
2. 触发留言互动
3. 给转发理由或行动提示

## 六、六种常用结尾方式

### 1. 金句收束

适合：观点、情感、职场、热点

特点：用一句判断封住全文。

示例句式：
- 真正让普通人翻身的，从来不是___，而是___。
- 你不是___，你只是___。

优点：记忆点强，适合截图。
风险：如果前文论证不够，会显得硬拗金句。

### 2. 提问互动

适合：几乎所有类型

特点：抛一个读者愿意回答的问题。

示例句式：
- 你最有共鸣的是哪一句？
- 如果现在让你认真开始一项副业，你最想做的是什么？

优点：提高留言率。
风险：问题太空会没人回。

### 3. 行动提示

适合：搞钱、成长、知识、复盘

特点：让读者知道接下来可以怎么做。

示例句式：
- 别急着问___，先想清楚___。
- 从今天开始，先把___做好。

优点：提高实用感。
风险：动作太大，读者不愿执行。

### 4. 指向性转发

适合：情感、职场、热点

特点：明确这篇适合发给谁。

示例句式：
- 如果你身边也有这样的人，把这篇发给他看看。
- 如果你也认识一个总说“撑不住了”的朋友，把它留给他。

优点：直接提高转发率。
风险：如果前文没有足够共鸣，转发指令会显得生硬。

### 5. 鼓励收尾

适合：成长、职场、AI 焦虑、搞钱、副业

特点：在判断之后，补一句让人愿意继续往前走的话。

示例句式：
- 你不用一下子跑很快，先别停在原地就够了。
- 真正重要的，不是你今天立刻变强，而是你开始知道自己该往哪儿补。

优点：能缓和焦虑，让读者更愿意接受前文判断。
风险：如果写得太轻，会变成泛泛安慰。

### 6. 宽慰 / 陪伴 / 社群引导

适合：情感、职场、AI 焦虑、长期主义、自媒体成长

特点：让读者感到自己不是一个人，也可以继续一起走。

示例句式：
- 如果你最近也有同样的不安，至少先别急着否定自己。
- 如果你也正在经历这个阶段，可以一起慢慢练、慢慢补。
- 如果你想持续看这类内容、一起学习和更新，也可以进群一起交流。

优点：更有人味，也更适合承接长期关系和社群动作。
风险：如果前文铺垫不够，突然引导进群会显得硬。

结尾不必每次都用反问句。根据任务目标，可以在提问、鼓励、宽慰、行动提示、转发引导、社群引导之间切换。

如果文章本身在处理焦虑、职业不安、成长迟滞等议题，很多时候“鼓励 + 宽慰 + 轻行动提示”会比单纯反问更自然。

如果文章目标里包含加群、关注、持续学习，也可以在结尾自然接一句轻社群引导，但前提是前文已经建立足够信任。

不要把“欢迎留言”当成唯一默认动作。结尾应该服务这篇文章真正的传播目标。

## 七、不同内容类型的开头/结尾偏好

### 情感共鸣型
- 开头：故事 / 场景 / 情绪直戳
- 结尾：金句 + 提问 / 指向性转发 / 宽慰陪伴

### 知识解释型
- 开头：问题 / 反常识 / 结果先给
- 结尾：判断句 + 行动提示 / 鼓励收尾

### 热点评论型
- 开头：热点 / 观点先给
- 结尾：立场判断 + 提问 / 轻转发引导

### 职场成长型
- 开头：朋友一句话 / 高频痛点场景
- 结尾：判断句 + 转发点 / 鼓励收尾

### 搞钱/副业型
- 开头：提问 / 普遍误区
- 结尾：行动提示 + 提问 / 鼓励收尾

### 自媒体复盘型
- 开头：结果先给 / 踩坑一句话
- 结尾：经验总结 + 提问 / 轻社群引导

## 九、最后提醒

好开头不是“华丽”，而是让人愿意继续读。好结尾不是“客气”，而是让人记得住、愿意说、愿意转。
