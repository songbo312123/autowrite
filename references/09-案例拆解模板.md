# 09-案例拆解模板

这份文件用于把一篇文章、一个案例、一次传播结果拆成可复用资产。

## 一、案例拆解的目的

拆解不是抄结构，而是回答：
- 它为什么能打动人
- 它靠什么被点开
- 它靠什么被读完
- 它靠什么被转发
- 哪些方法可以复用，哪些只是这个案例的偶然性

## 二、通用拆解框架

### 1. 基础信息
- 案例名称
- 内容类型
- 目标人群
- 传播目标（高打开 / 高完读 / 高转发 / 高收藏）
- 大致主题

### 2. 标题拆解
看：
- 有没有人群感
- 有没有情绪感 / 收益感 / 反常识感
- 核心冲突是什么
- 信息缺口在哪里
- 这个标题为什么会让目标人群点开

### 3. 开头拆解
看：
- 开头属于哪种起手方式
- 前三句有没有完成抓注意 / 确认相关 / 给阅读理由
- 有没有具体场景或一句高共鸣表达

### 4. 结构拆解
看：
- 它整体走的是哪种正文结构
- 每一节在推动什么
- 读者为什么愿意继续往下读
- 有没有明显的转折或递进节点

### 5. 情绪拆解
看：
- 主情绪是什么
- 次情绪是什么
- 文章在哪些句子里把情绪拉满了
- 它是怎么避免只有情绪没有价值的

### 6. 价值拆解
看：
- 提供的是判断、解释、方法，还是表达出口
- 读者看完能带走什么
- 这篇更偏转发，还是更偏收藏

### 7. 传播拆解
看：
- 哪句话最适合被截图
- 哪个观点最适合被转述
- 为什么读者会想发给别人

### 8. 可复用点
总结：
- 可以直接复用的标题机制
- 可以复用的开头方式
- 可以复用的结构
- 可以复用的结尾设计

### 9. 不可盲抄点
总结：
- 哪些地方依赖作者身份、时机、热点、具体经历
- 哪些表达换题就会失效

## 四、不同内容类型的拆解重点

### 情感共鸣型
重点看：
- 哪句话让人觉得“这是我”
- 场景是否具体
- 结尾是否给了表达出口

### 知识解释型
重点看：
- 问题是否讲得足够清楚
- 误区和真相的反差是否成立
- 结构是否便于收藏和转述

### 热点评论型
重点看：
- 有没有借势但不空泛
- 有没有把热点翻译成普通人的情绪和判断
- 观点是否足够明确

### 职场成长型
重点看：
- 痛点是否真实高频
- 机制解释是否站得住
- 有没有给到出路感

### 搞钱/副业型
重点看：
- 收益预期是否真实
- 误区纠偏是否打中人
- 是否兼顾焦虑安抚和方法价值

### 自媒体复盘型
重点看：
- 结果是否清楚
- 过程是否真实
- 经验是否可复制

## 五、拆解时的常见误区

- 只说“写得好”，但说不出好在哪里
- 只拆标题，不拆正文承接
- 把作者气质误当成可复制技巧
- 只看点击逻辑，不看转发和完读逻辑
- 只看内容本身，不看目标人群与时机

## 六、最后提醒

企业级案例拆解的目标不是膜拜爆款，而是把爆款拆成方法、结构、触发器和限制条件。只有这样，案例才能真正进入知识库。
