# iteration-1 评估总结

## 本轮范围
- 测试题数量：8
- 覆盖内容类型：情感共鸣型、知识解释型、热点评论型、职场成长型、搞钱/副业型、自媒体复盘型
- 覆盖增强模块：经典引用、桥段转述
- 输出类型：6 篇完整文章、1 篇完整文章（引用增强）、1 份热点蒸馏 + 骨架

## 脚本评分结果
- knowledge-01：35/40
- money-01：35/40
- emotion-01：30/40
- career-01：30/40
- creator-01：30/40
- quote-01：30/40
- scene-01：30/40
- hot-01：20/40

### 脚本层结论
1. 知识解释型、搞钱/副业型目前最稳，已经能稳定进入强稿区。
2. 情感、职场、复盘、引用增强、桥段转述增强目前都能达到“可发”水位，但长度和结构标记还不够强。
3. 热点评论型因为本轮按“蒸馏 + 骨架”交付，天然拿不到完整文章脚本分，不适合直接和长文共用同一评分口径。
4. 当前 `score_article_checklist.py` 对结构的判断过于依赖固定小标题标记，导致多篇可读样稿在 `structure_hint` 上丢分。

## 人工评审结论

### 最稳的内容类型
- 知识解释型：最容易形成“反常识判断 + 机制拆解 + 收藏感”闭环。
- 搞钱/副业型：现实张力最强，标题与正文承接也比较自然。

### 最容易写虚的内容类型
- 热点评论型：如果没有先补足事实层和情绪样本，很容易只剩立场。
- 情感共鸣型：如果只停在感受命名，很容易少一层价值抬升。

### 增强模块判断
- 经典引用：`quote-01` 基本自然，但因为引用可靠性为 medium，后续正式对外稿件仍需要核对译文。
- 桥段转述：`scene-01` 的效果比直接引用更稳，能增强现实张力，而且没有明显压过正文主线。
- 从首轮表现看，桥段转述依然是更适合企业化复用的增强方式。

### 标题与正文承接
- `knowledge-01`、`money-01` 承接最好，标题承诺和正文展开一致。
- `emotion-01` 标题有共鸣，但正文后段的抬升可以再更锋利。
- `creator-01` 有收藏价值，但标题还可以更有结果冲突感。

### 典型问题
- 多篇文章虽然可读，但段落骨架标记不统一，不利于脚本评分和后续批量比较。
- 热点评论题目前只做了蒸馏与骨架，没有形成可直接横比的完整长文样稿。
- 情感型和职场型目前共鸣较强，但“截图句”和更尖锐的判断还不够多。

## 当前最值得保留的规则
1. 知识解释型优先走“反常识判断 → 机制拆解 → 行动顺序”。
2. 搞钱/副业型优先走“现实张力 → 常见误区 → 更现实的进入路径”。
3. 桥段转述优先用于搞钱、职场、成长类题，不宜写得比正文更重。
4. 热点评论型必须单独区分“蒸馏输出”和“完整文章输出”的评估口径。

## 下一轮最优先动作
1. 优化 `score_article_checklist.py`，让它能识别更多结构标记，不只盯固定格式。
2. 为热点评论型单独补一个“蒸馏/骨架型输出”评分规则。
3. 给情感型、职场型样稿补更明确的小标题结构，增强批量评估一致性。
4. 继续扩大桥段转述库，优先补“稳定与不甘”“错位努力”“长期主义”三类主题。
