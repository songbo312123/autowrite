### 桥段转述建议
- 作品：《月亮与六便士》
- 作者：毛姆
- 核心桥段：现实秩序与内心理想的撕扯
- 核心张力：一边是可见的现实利益，一边是更难放弃的内心召唤
- 适合类型：搞钱/副业型 / 职场成长型 / 知识解释型
- 适合主题：选择 / 副业 / 理想与现实 / 重新选择 / 风险与稳定
- 推荐用法：桥段转述
- 使用提醒：更适合转述其张力，不适合把流行总结句当作小说原文。

### 桥段转述建议
- 作品：《百年孤独》
- 作者：加西亚·马尔克斯
- 核心桥段：重要变化常常在漫长、安静、难被看见的时间里发生
- 核心张力：很多真正的变化不是爆发出来的，而是积累出来的
- 适合类型：搞钱/副业型 / 自媒体复盘型 / 知识解释型
- 适合主题：长期主义 / 积累 / 复利 / 慢变化
- 推荐用法：意象借用 / 桥段转述
- 使用提醒：更适合做意象化辅助，不宜假装是精确原文。

### 桥段转述建议
- 作品：《老人与海》
- 作者：海明威
- 核心桥段：人在长期对抗里靠的不是热血，而是韧性和承受力
- 核心张力：很多值得的事，不是靠一口气赢，而是靠不被中途消耗掉
- 适合类型：搞钱/副业型 / 自媒体复盘型 / 知识解释型
- 适合主题：韧性 / 坚持 / 长期主义 / 创作
- 推荐用法：桥段转述 / 主题转述
- 使用提醒：适合强化韧性逻辑，但别写成空洞鸡汤。
